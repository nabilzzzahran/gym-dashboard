
# Gym Progress Dashboard

A workout tracking and analytics project built with Python.

## Tech Stack

- Python
- FastAPI
- Uvicorn

## Current Features

- Health check API endpoint (`/health`)
- Interactive API documentation (`/docs`)

## Setup

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python -m uvicorn app.main:app --reload
```
